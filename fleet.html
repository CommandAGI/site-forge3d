Reading a state

What each word means

registered
The printer is in the register with its camera. No host has connected to it yet.
live
A real host is connected and reporting. Shown only when that is true.
interrupted
The link was lost during a job. The job record shows the state as unknown until a host reports again.

The full set of states and the rules for each are on the CommandAGI platform.
